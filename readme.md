# Møbler Norge

## Beskrivelse

Møbler Norge er en prototype på en nettbutikk for møbler. Brukeren kan se produkter, søke, filtrere etter kategori, legge produkter i handlekurv og simulere en bestilling.

## Målgruppe

Målgruppen er personer som ønsker å kjøpe møbler på en enkel og oversiktlig nettside.

## Teknologier

- HTML for struktur
- CSS for design
- JavaScript for funksjonalitet
- Senere: Java-backend
- Senere: SQL-database
- Senere: API-er

## Planlagte funksjoner

- Produktoversikt
- Søkefunksjon
- Kategorifilter
- Handlekurv
- Checkout-skjema
- Adminside
- Database for produkter og ordre

## Fokus

Prosjektet skal ha fokus på brukervennlighet, enkel kjøpsflyt og CRO-prinsipper.
